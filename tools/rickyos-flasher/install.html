安装前与遇到问题时

电脑找不到设备＋

检查 USB 数据线，关闭占用串口的网页或终端。仍无法识别时，按设备官方说明进入 BOOT 下载模式，不要照其他机型操作。

备份失败或安装中断＋

备份失败不允许写入。若写入已经开始，请保持 BOOT 模式和连接，保存记录并联系 Ricky AI Studio；不要自行整片擦除或重启。本站暂不提供恢复刷写。

原厂设备与书籍数据＋

原厂系统的首次安装还在验收，暂未开放；识别到原厂系统时只保存备份，不会写入。网站不操作 SD 卡，完整 Flash 备份也不含 SD 卡，请另行备份书籍和阅读数据。
