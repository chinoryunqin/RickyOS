安装前与遇到问题时

电脑找不到设备＋

检查 USB 数据线，关闭占用串口的网页或终端。仍无法识别时，按设备官方说明进入 BOOT 下载模式，不要照其他机型操作。

安装中断怎么办＋

每段写入都会让设备自己校验，失败时网站不会重启设备。请保持连接，保存操作记录后重新连接再装一次；仍不行请联系 Ricky AI Studio。

原厂设备与书籍数据＋

原厂设备不需要先刷其他系统，网站会识别并完整安装 RickyOS，原厂内部文件会被清理。想保留原厂系统，可以勾选先备份完整 Flash。网站不操作 SD 卡，卡上的书不受影响。
