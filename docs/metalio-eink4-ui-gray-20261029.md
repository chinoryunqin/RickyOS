## 修正依据

- `ActivityManager.cpp` 原来仅为 Read Pico / Plus 编译直接灰阶菜单；普通版始终是黑白。
- `RickyHomeUi.cpp` 的大竖屏分支要求内容高度至少 900，小屏退回简化布局。
- JPEG / PNG 缩略图入口原来在普通版生成抖动黑白 BMP，丢失封面层次。
- 视觉基线为 `docs/design-system.md` 与原有首页落地稿：字体层级、反白选中、语义灰色、卡片与留白。

## 实现与限制

菜单使用一次绘制的 4bpp 工作画布，统一量化为四个物理灰阶；面板能力仍明确报告四级。
复用当前板卡已经使用的灰阶覆盖波形、物理清理和 BUSY 超时状态，不启用未验证的 Absolute LUT，
也没有复制 Plus 并行屏的 16 灰阶波形。厂商公开说明目前也只提供真四灰阶路径：
https://github.com/CloudZao/Metalio-E-INK4/blob/main/docs/epd-bayer-dither-gray.md 。
16 级物理灰阶尚未验证。工作画布位深不能作为面板支持 16 级的证据。

只给普通版增加一个可复用的 192,000 字节 PSRAM 画布，禁止回退占用内部 RAM；
逐行生成灰阶选择位平面，栈上最多 128 字节，不增加两个整屏位平面。
内存不足或提交失败走现有可读黑白回退。控制器提交成功状态跟随实际光学状态，超时保持 Unknown。
刷新需要原有清理，可能闪屏；不把 Plus 的速度和残影验收移用于本机。

用户明确要求与当前 Plus / Pico 同一套新版界面。dev14 曾将大屏首页整图缩小，
并只核对绘制函数与软件代理图，这一做法已被用户实拍否定。本轮移除该首页画布、
整图采样及触控逆变换，恢复原生共享路由，在真实像素尺寸下直接排版文字。

候选使用同一套 Noto 字体源的真实字重及原生字号：正文 / 书名 21px，说明 17px，
小标题 25px，页标题 29px，日期与统计数字 40px。保留原设计的日期头像、探头形象、
继续阅读卡、双栏统计及最近封面。书库标题计数按实宽预留，仍为六本书的 3×2 书架。
页面与触控使用同一组实际布局矩形；相机与蜂窝控制不参与本次视觉核对。

此处记录候选实现，不把未经过实屏检查的数值写成既定设计规范。

封面缓存使用 `thumb_g8_<height>.bmp`，保留灰度源像素，新文件名避开旧黑白缩略图；
不删除原书、阅读记录、原缩略图或章节缓存。详见 `file-formats.md`。

## dev16 变化像素刷新实验（2026-11-02）

用户授权先试保留上一帧的方案。当前整页提交固定 HALF，板卡驱动将其解释为
BlackPulse 两次端点更新，再叠加灰阶；Plus / Pico 的局部灰阶接口在普通版为空操作。
阅读用 PaperMono 组合 AA 只有一个中间灰，不能直接替代当前四灰界面。

实验由普通版环境独立开启 `FREEINK_METALIO_UI_RETAINED`，布局、字体、阅读及其他板卡路由保持原状。
在 SDK 驱动内保存上一张已提交的 4bpp 原生画面（额外 192,000 字节 PSRAM，分配失败回退原 HAL 路径）。
它必须跨页面存活，不能放入栈或内部 / DMA 堆；生命周期跟随驱动，析构释放。
工作行 128 字节、LUT 副本 110 字节，不增加整屏选择位平面。

- 按实际四灰量化比较，完全相同画面不触发屏幕激活。
- 变化像素先驱动到目标黑 / 白端点，再仅为变化像素叠加原有灰阶；未变化像素编码为不驱动。
- 端点 LUT 复用当前 Metalio FAST 的转换类，清零两个保持类；其余波形时长、电压尾部及灰阶 LUT 不变。
- 五次已完成的变化更新后走一次原有清理；启动、强制清理、普通绘制、阅读路由、重同步、休眠和 BUSY 失败使旧帧失效。
- 仅在完整刷新完成后提交新历史；任一阶段失败停止后续 RAM 写入，恢复后重新清理。

实屏验证前不宣称“无残影”或“无闪屏”。该方案减少了正常变化更新的一次像素激活，
但灰色到端点的光学恢复是否充分，必须与同页强制清理后的实物画面比较。
日志使用 `[MUI] clean/delta` 分别记录端点、灰阶及总提交时间，不能混同点击到完成时间。

已通过：真实驱动的 16 种四灰转换、保持像素、量化等价无操作、清理周期、强制清理、
重同步、非 UI 绘制、休眠、PSRAM 失败及全部五个清理 / 变化阶段的 BUSY 失败检查（ASan/UBSan）；
真实 facade 的原阅读路由及实验 UI 路由；原生灰阶解码 / 取消 / OOM 检查。
完整 CI 仍在原有未初始化 submodule 处阻断；此工作树无 X3/X4 硬件构建环境，未构建其镜像。
dev16 编译、刷机及光学验收状态随运行证据另记，不将 dev15 的布局确认当作刷新实验验收。
