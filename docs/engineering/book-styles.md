# 精排书样式还原（书内字体、字号、颜色）· 2026-10-21

目标：尽量按原书显示精排 EPUB——书里自带的字体、每段的字号、文字颜色。开关沿用
“图书内置样式”（`SETTINGS.embeddedStyle`，默认开）。先在 Read Pico 上做，主代码树里实现，
A4 / Plus 之后同步。

参考样书：《间客【典藏版】精排》——6 个书内字体（2 KB–571 KB 的子集），15 个 `@font-face`
（一部分指向系统字体名：宋体 / 楷体 / 黑体 / 仿宋），主样式表 79 处 `font-family`、79 处
`font-size`、78 处 `color`。

## 参考：厂长固件（read-pico-reader）

只看思路，不搬代码（2026-10-15 之后的新代码可能是禁止商用的个人学习许可）。可借鉴：

- 按需装载：只在某个 `font-family` 真被选用时才把字体解压进 PSRAM；装不上就回落阅读字体。
- 书里放了字体但没写 `@font-face` 时，按文件名主干匹配。
- `font-family` 是候选列表，取第一个能解析的名字；`@font-face` 里的 `font-family` 是命名，不是选用。
- 装字体前给插图解码留 PSRAM（他实测留 1.6 MB，否则翻几页后插图消失）。
- 它不支持字号和颜色；不处理 WOFF 和 EPUB 字体混淆。

## 设计

### 1. CSS

`CssStyle` 增加三项（CSS 缓存版本 +1）：

- `fontFamily`：候选列表解析后的书内字体序号（`BookFontSet` 的下标，0 = 不指定）。
- `fontSize`：`CssLength`（em / % / px / pt / rem / 关键字 small、large…），相对父元素累乘。
- `color`：解析 `#rgb`、`#rrggbb`、`rgb()`、常见颜色名，换算为墨水深浅 0–15（15 = 纯黑）。

`@font-face` 收集到 `BookFontSet`：family 名 → ZIP 内路径（url 相对所在样式表解析）；
`local("宋体")` 这类系统字体名映射到我们的在线字体（宋→RickySerif、楷→LXGWWenKai、
黑→RickySans、仿宋→ZhuqueFangsong），没装就忽略。

### 2. 排版

`ChapterHtmlSlimParser` 的样式栈多算三项生效值：字体序号、字号倍率（1/16 em 为单位）、墨水深浅。
`ParsedText::addWord` 带上它们；测宽、断行按每个字自己的字体和字号；一行的行高取该行最大字号。

### 3. 存储

`TextBlock` 的 arena 增加可选的逐字数组（字体序号、字号、深浅），整行都是默认值时不占空间
（与 focus 数组同样的做法）。排版缓存版本 +1；“书内字体集合”的签名进入排版缓存的键。

### 4. 字体

`BookFontSet`（每本书一个）：书内字体按需解压到 PSRAM，按（字体，像素字号）建 `TtfEpdFont`，
注册为动态字体编号，缺字回退到阅读字体。阅读字体的其他字号：矢量字体直接建新字号；内置位图字体取最接近的字号。
PSRAM 预留给插图与页缓存，不够就不装（回落阅读字体）。

### 5. 绘制

逐字取字体编号；16 级通路按深浅写入（`blendGrayscale16Pixel` 已有墨水深浅参数）；
黑白通路按阈值决定黑或白。

## 步骤

1. CSS：`font-family` / `font-size` / `color` / `@font-face` 解析与缓存，主机测试。
2. 书内字体集合：从 EPUB 收集字体、按需装载、动态字体编号、缺字回退。
3. 排版与存储：逐字字体与深浅（字号先跟正文一样），排版缓存版本。
4. 绘制：16 级深浅、黑白阈值；真机对比《间客》。
5. 字号：逐字字号、混排行高、标题放大。
6. 视情况：背景、边框、行高等。
