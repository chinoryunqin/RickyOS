# RickyOS Markdown 阅读（1.1.5）

文件扩展名 `.md`（不区分大小写），从书库或储存打开，沿用 EPUB 阅读器的
字体、翻页、字号、进度及阅读菜单。TXT 的转换与上游非产品固件保持原样。

## 本次支持范围

- `#` 到 `######` 的 ATX 标题（井号后加空格或制表符），自动生成六级目录。
  目录去除粗体／斜体／行内代码及链接标记，只显示文字；点选跳到标题所在页。
  围栏代码、四空格缩进、引用内的井号不作为目录标题。
  沿用 TXT 章节规则，目录标题另起新页，短小节可能出现更多留白。
- `**粗体**`／`__粗体__`、`*斜体*`／`_斜体_` 和单反引号行内代码。
- 一级有序／无序列表；连续列表使用现有 EPUB 列表排版和编号。
- `> 引用`、横线分隔、空行、反引号／波浪号围栏代码块。
- 基础行内链接显示文字，图片显示替代文字；不下载、嵌入或打开目标 URL。
- Markdown 反斜杠标点转义。原始 HTML 作为文字转义，不执行标签。
- 中文 UTF-8（含 BOM）及现有 GBK 转码路径。
- 竖线表格：表头、分隔行、空单元格、左右／居中对齐和单元格内基础排版；
  支持省略外侧竖线、CRLF、末行无换行、转义竖线及代码中的竖线。

## 表格阅读

使用现有 EPUB 表格排版，不将整张表截图，也不缩小字体强塞进屏幕。
普通两列／三列表格按列显示，文字自动换行并可跨页；表头沿用阅读器粗体，
行之间用细线分隔。列数超过四列、列宽不足三个行高、单元格超过 512 UTF-8
字节或 32 个分词时，现有阅读器将该行转为纵向排列，保留各单元格内容。
因此同一张表可能同时有横向及纵向行；跨页不重复表头，页末可能只容纳表头。
这是窄屏的现有流式阅读方式，不等同于桌面浏览器的表格网格。

转换器最多识别 16 列、表头最多 3 KiB、数据行最多 4 KiB（按转码后的 UTF-8
计）。超限、错误分隔行或多出的单元格以原文回退，避免截断／静默丢内容；
少于表头列数的有效数据行补空单元格。不支持合并单元格或嵌套表格。

这是面向设备阅读的有限子集，不承诺完整 CommonMark/GFM。暂不支持
任务复选框、脚注、嵌套列表、Setext 标题、引用式链接、图片渲染和代码语法高亮。
普通文本行按独立段落处理。目录标题原始行需小于 192 UTF-8 字节；
超长标题仍在正文显示，不加入目录。围栏行识别同正文的 4 KiB 行上限。
不完整／不识别的语法尽量保留文字；请勿宣传为完整 Markdown 编辑器。

## 内存与缓存

不引入解析库或新 heap 缓冲。复用原有两个 8 KiB 转换缓冲：第一个拆成
1 KiB 输入、4 KiB UTF-8 行缓存与 3 KiB 表头前瞻，第二个继续用于输出。
只缓存一行待确认的表头；最多 16 个固定栈上单元格偏移，不缓存整张表。
单行超过 4 KiB 时
该行完整流式输出为文字，不截断、不分配更大的缓存。内联嵌套最多四层。
代码块保留空格与换行，仍使用用户选择的阅读字体，不内嵌新的等宽字体。

MD 转换标记由 2／3／4 升到 5，仅按需重建对应 HTML／目录／分页，不清空 SD 卡。
MD `chapters.bin` 语义版本升到 2，记录大小仍为 196 字节，保留原始 ATX 前缀
供 metadata 派生层级。TXT／上游非产品版本仍用章节索引版本 1。
旧 MD 的精确阅读位置通过旧 source map 保存源坐标，再映射到新页面；
成功保存新进度前保留检查点。只有页码的更老记录仍走比例迁移，不承诺精确源位置。
首页的零坐标记录作为已知书首处理；非首页的未知零坐标保留旧进度并报告失败。
格式见 [file-formats.md](../file-formats.md)。

## 验证

```sh
cmake -S test -B build/test
cmake --build build/test --target MarkdownToHtmlTest TxtToHtmlTest txt_chapter_index_test markdown_chapter_index_test
ctest --test-dir build/test -R '^(product\.|Markdown\.|MarkdownChapterIndex\.|TxtToHtml|TxtProgressTest|TxtChapter)' --output-on-failure
pio run -e rickyos_readpico
pio run -e simulator_rickyos
```

真机验收需用中文 MD、代码块、长行和大文件检查打开、连续翻页、字体／字号
变化、退出重进、旧版进度迁移，以及低内存／中断转换后重试。构建／主机测试
不能证明墨水屏效果、SD 卡时延和真实剩余堆安全。

原生模拟器专项：`tools/rickyos-browser/check_markdown_tables.py --sample <本地 MD>
--output build/table-qa`。可选 `--baseline <真实 MD3／MD4 原生程序>` 验证实际旧版缓存
迁移。使用独立临时 SD，输出 HTML／截图仅供本地验收，不上传用户文档。
本次实际样本包含四张表及 29 个标题。MD5 目录元数据共 30 项（含书名），
与正文标题文字／层级一致，菜单点选正确跳到目标标题所在页。
原生程序连续翻至第 30 页和结束面板、退出重进及
改变行距触发重排均通过。内置 high-DPI 字体 ID 固定，单独改 JSON 的字号
不能证明换字号；SD 字体及真机字体切换仍在硬件验收矩阵内。
