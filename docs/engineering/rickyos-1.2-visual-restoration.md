# Read Pico 1.2 视觉补齐（2026-10-11）

基线 `ff540898`，本地 `codex/rickyos-1.2-design`。保留已有 SDK 工作区修改，
未合并／覆盖另一份 native-gray 工作区。用户授权后仅提交、推送私有实验分支，
不合并到正式版、不发布固件。

## 本次补齐

- 灰色文字真正使用原生灰阶墨色：`kInk2=4`、`kMute=8`，作用域结束恢复，
  不再由 SDK 灰色文字回退成纯黑。抗锯齿覆盖度与现有底色混合，选中白字也保留覆盖度。
- Caption、Headline Medium、Title Bold、Numeric Display 四个 UI 字体重新生成
  4-bit 位图；行高／基线不变，无假粗体。BODY 全字集、已有 SD `.cpfont` 和用户
  正文字体／字号／抗锯齿偏好未替换，不能称为“所有字体升级 4-bit”。
- Read Pico 高精度 UI 固定进入全屏阅读菜单，包括 SD 卡保存旧 Toolbar 偏好的用户；
  隐藏无效菜单样式开关，原持久化字段不改。目录、文字设置、查词、更多及返回沿用回调。
- 首页统计数字和图表分开；最近书名预留两行与独立信息行。小默认封面改用小字号，
  不再挤压为省略号，重复格式标签留在封面外。保持四本最近书的设计。
- 书库信息、存储容量、设置辅助信息、阅读顶栏／页码／百分比补上次级墨色。
- Activity 栈返回增加诊断日志，浏览器预览识别返回后的活动，避免误报仍停留阅读菜单。

没有新增灰阶全屏快照／堆缓冲，没有改分区、波形、VCOM 或阅读内容缓存格式。
