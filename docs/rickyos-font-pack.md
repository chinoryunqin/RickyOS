# RickyOS 常用中文字体包

这是 SD 字体包，不是固件；导入字体不需要刷机。

| 设备中的名称 | 字体来源 | 用途 |
| --- | --- | --- |
| RickySans | Adobe 思源黑体 CN | 无衬线正文，清楚规整 |
| RickySerif | Adobe 思源宋体 CN | 衬线正文，接近印刷书籍 |

两套都是从官方静态 OTF 的 Regular / Bold 转换而来，包含真正的粗体。
提供 12、14、16、18、20、22 档，使用 CrossMux 原生 cpfont v4 格式。
12/14/16 同时覆盖 Read Pico 高密度 UI 的备用尺寸。字号参数以转换器
150 DPI 为基准，不是 Read Pico 约 300 PPI 面板上的实际物理磅数；
建议先预览 18、20，再按个人阅读距离选定，不自动修改已有设置。

## 导入（任选一种）

### SD 卡复制

1. 安全关机，把 SD 卡插入读卡器。先备份 SD 卡现有内容。
2. 解压 `RickyOS-Fonts-SD.zip`，将其中 `fonts/RickySans`、
   `fonts/RickySerif` 两个目录复制到 SD 卡的 `/fonts/`。
   不要覆盖已有同名字体。请把各目录内的 `OFL.txt` 一起保留。
3. 安全弹出 SD 卡，装回并启动设备。

### 设备网页上传

1. 在设备打开「文件传输」，加入网络或创建热点。
2. 电脑浏览器打开设备屏幕显示的地址，进入「字体」。
3. 解压字体包；分别选择 `RickySans` 和 `RickySerif` 目录上传。
   一次只上传一个字体目录，不选择整个 `fonts` 目录。
   网页只接受 `.cpfont`，不接受 ZIP/OTF；各字号文件应全部上传。
4. 两个 `OFL.txt` 无法通过字体上传表单上传，请在分发时保留本包许可；
   若字体装入产品出货，请改用 SD 复制方法一并安装许可文件。

导入后，在 RickyOS「设置 → 阅读与字体 → 文字设置」中选择字体和字号；
旧固件对应「设置 → 阅读 → 文字设置」。保留原有字体，可随时切回。
中文菜单仍优先使用固定的内置黑体，不会随阅读正文改为宋体。
内置字体本来就是 Noto Sans CJK 子集；相近的思源黑体不会凭导入就让
每个菜单字形发生明显变化。整页模拟加粗的修正需安装新版 RickyOS 固件，
与 SD 字体导入是两件独立的事。

字体改变会重新分页，页码可能变化。本包全部字号的完整 Regular/Bold 文件
都超过单字体 Flash 加速缓存的 6,549,504 字节限制，使用 SD 读取。
本轮更新的 RickyOS 在退出独立「文字设置」时会自动跳过无法容纳的加速缓存，
不写缓存、不把正常导入误报为失败。旧固件若显示加速失败，确认提示即可
继续从 SD 阅读；阅读工具栏另行询问加速时选择跳过。不要格式化卡或删字体。
这些是简体中文地区子集，并非全 Unicode 字库；不保证生僻扩展区、
少数民族文字或 Emoji 覆盖。

## 来源、许可和校验

官方项目：[思源黑体](https://github.com/adobe-fonts/source-han-sans)、
[思源宋体](https://github.com/adobe-fonts/source-han-serif)。使用 SIL OFL 1.1，
完整版权与许可附在每个字体目录的 `OFL.txt`。转换属于修改版，
因此转换后的主名称使用 RickySans / RickySerif，避开保留字体名 Source；
RickyOS 不宣称这是自研字形或获得 Adobe 背书。字体不得单独销售。

`manifest.json` 记录固定官方提交、原始文件 SHA256、每个转换文件的
SHA256/CRC32、字形数、字号、样式和 Flash 缓存适用性。
构建脚本验证常用汉字字符集、ASCII、区间、样式与所有字形的位图边界，
`SHA256SUMS` 可在解压目录使用 `shasum -a 256 -c SHA256SUMS` 检查。
模拟器验证不等于真实墨水屏效果、速度或内存验证。

微软雅黑、苹方等商业字体不随包分发；拥有相应许可的字体文件可以另行
导入。Read Pico 的 PSRAM 固件还支持从 SD 加载 TTF/OTF/TTC；直接字体
不要和 cpfont 放在同一字体目录，以免被 cpfont 优先覆盖。
