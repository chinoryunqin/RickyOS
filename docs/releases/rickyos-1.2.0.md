# RickyOS 1.2.0

适用于 MindReset 小纸 Read Pico（RDP-G01-W）。

## 安装与更新

- 网页安装：[RickyOS 安装工作台](https://chinoryunqin.github.io/RickyOS-site/install.html)。
  使用电脑 Chrome / Edge，原厂系统、CrossMux 或其他系统均可直接安装，完整备份可选。
- 已装 RickyOS：设置 → 系统 → RickyOS 更新。
- 1.1.5 的 Markdown 排版、表格、标题目录和中间键待机修复都保留在 1.2 里。

## 这一版

### 新的样子

- 全新的灰度界面：首页、书库、应用、存储和设置都重新设计，菜单和设置用同一种列表样式。
- 书的封面改为灰度缩略图，显示更细腻。
- 开机整理 SD 卡时，小狗会告诉你它在做什么。

### 读书

- 新增阅读模式：原版、小狗伴读、沉浸、古籍。古籍模式竖排，列间有界行，版心显示章节名（没有章节名时显示书名）。
- 新增阅读线，六种样式，在阅读菜单里选。
- 字号最大 32 号；新增字重调节，字号和字重在阅读菜单里直接调。
- TTF / OTF 字体也能使用字体加速，翻页更快。字体文件太大无法加速时会提示。

### 阅读统计

- 连续阅读改用爪印标记，新增月历。
- 新增徽章和每月阅读月报。

### 传书和下载

- 新增 USB 传书：用数据线连上电脑，SD 卡就是一个 U 盘，可以直接拷书。
  拷完在电脑上弹出磁盘即可返回；电脑没有反应时，按返回键退出。
- 字体和图片下载改走国内线路，遇到线路不通会很快切换。

### 更快

- 回到首页、进入书库更快，封面只准备一次。
- 大书第一次打开更快，并显示准备进度；打开书时马上提示"正在打开"。
- 刷机或换卡后第一次开机，会先把书库和封面整理好，之后使用不再卡顿。

### 移除

- 移除 OPDS 书库、SD 卡插件和 XTC 格式。

## 已知情况

- USB 传书走的是全速 USB，拷书约 0.6 MB/s。Mac 上打开存了大量书的文件夹时，
  访达会读取每本书生成预览，可能导致磁盘被电脑断开；此时按返回键退出即可。
  直接把书拖到磁盘根目录可以避免。
