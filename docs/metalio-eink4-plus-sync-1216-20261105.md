# 普通版 E-Ink 4 同步 Plus 1.2.16

候选版本为 `1.2.16-metalio-dev18`。应用改动来自已发布的 Plus
1.2.16 源码快照 `f1cdb672696af8d4b549117bec0fc70e94366a41`，
以普通版原移植输入 `2973acbb` 作三方比对，合入现有普通版分支
`60f238ac`。两个 Plus 快照均按原清单恢复并核对散列。
普通版使用现有 ESP32-S3、SSD1677 SDK 补丁和双应用槽。
Plus 的 S31 屏幕、充电、固件发布配置和字体元数据搬移属于机型专用实现。
WebP 解码仍受可选构建开关控制，普通版候选使用现有 JPEG、PNG 路径。

- 阅读页按 480×800 的原生字体和布局计算。顶栏依信息栏设置显示时间、
  书名或章节与电量。进度条单列置于页码和全书百分比上方，横屏使用同一套计算。
  已存偏好继续生效，新设置默认显示左侧时钟和全书进度条。
  正文和菜单用同一页的全书百分比，进度跳转仍使用页起点定位。
- 全屏阅读菜单沿用 Plus 的四个快捷入口与反白选中。字号、字重、图像调节、
  书签、阅读模式、阅读线和进度入口位于主列表，较低频操作在「更多操作」。
  普通版复用原生触控尺寸和滚动列表。翻页热区可分别设置横屏和竖屏。
- 图片调节同步原图对比、亮度、对比度、缩放与按书保存。书架记忆上次目录，
  行距支持 80%～400%，Kindle 封面从书籍资源读取。EPUB 同步有界的格式错误恢复，
  以及保留 CSS 面板亮度和边框的绘制。缓存兼容见 [文件格式](file-formats.md)。
- 原生中文字体以仓库固定的 Noto Sans SC 来源重新生成。
  新菜单与图片调节页复用现有灰阶绘制，普通版保持 dev17 的 2bpp UI 历史及按需阅读平面。

构建使用 `rickyos_metalio_eink4`、`rickyos_metalio_eink4_core` 和
`simulator_rickyos_metalio_eink4`。普通版字形检查使用
`python3 scripts/tests/test_settings_translations.py --metalio-native`。
全仓 CI 的前置检查仍报告未初始化子模块。通用 14、16、18 pt 字库的旧子集仍缺
8 个本轮增加的文案字形，普通版的独立字库覆盖这些字符。

硬件验收待安排。实机重点检查菜单触控、黑闪与残影、图片设置效果、
阅读进度恢复和休眠唤醒。
