# RickyOS 角色设定（IP）

RickyOS 的 Logo 是我们的个人 IP：戴眼镜的 Ricky 和他的黑白小狗。这份设定把两个角色固定下来，
今后的宣传图、产品插画、动效和周边都按这里画，保证每次出现都是"同一个人、同一只狗"。

设定图在 [`characters/`](characters/)，都由 `src/images/sources/rickyos/approved-logo.png` 派生。

| 文件 | 内容 |
|---|---|
| `ricky_turnaround.png` | Ricky 全身四视图：正面、四分之三侧、正侧、背面 |
| `ricky_expressions.png` | Ricky 六种表情：开心（Logo 原样）、大笑、惊讶、思考、犯困、专心阅读 |
| `puppy_turnaround.png` | 小狗全身四视图：正面、四分之三侧、正侧、背面 |
| `puppy_expressions.png` | 小狗六种表情：吐舌开心（Logo 原样）、兴奋、歪头好奇、犯困、惊讶、安静微笑 |
| `duo.png` | 合照：Ricky 拿着墨水屏阅读器，低头看坐在脚边的小狗 |

## 1. 画风（两个角色共用）

- 纯黑白线稿，白底。只用纯黑和纯白，没有灰色、渐变、阴影、排线和纹理。
- 粗细一致的圆润描边，线头圆角；实心黑块只出现在设定里规定的位置（头发、裤子、小狗的耳朵和斑块）。
- 比例偏可爱：Ricky 约 3.5 个头高，小狗头大身小、四肢短。
- 画面里不放文字；需要文字时由版式另加，不画进角色图。

## 2. Ricky

**不可改动的锚点：**

1. **头发**：整块实心黑；刘海向前、略向一侧扫，发尾有几处小尖；头顶有一撮翘起的小呆毛。
2. **眼镜**：黑色圆角矩形镜框，两片一样大，中间细鼻梁。任何角度都戴着。
3. **眼睛**：默认是眯起的笑眼（倒 U 形弯线），画在镜片里。惊讶、专注等表情才改成小圆点眼。
4. **嘴**：一条简单的上扬弧线；大笑时张嘴，嘴里只画舌头的一条线。
5. **脸**：圆脸，两只耳朵露在头发外。

**服装（默认，四视图一致）：** 白色圆领短袖 T 恤（领口两道线），实心黑色长裤，白色系带运动鞋。

**常用道具：** 墨水屏阅读器——细黑边框、**白色屏幕**、屏上几行短横线表示文字。不要画成黑屏手机或平板。

## 3. 小狗

**不可改动的锚点**（以正面图里观众看到的左右为准）：

1. **左耳（观众左）**：高高竖起的尖耳，黑色，里面一道白。
2. **右耳（观众右）**：垂下来的折耳，整只实心黑。
3. **眼周黑斑**：两眼各在一块黑斑里，黑斑和两侧耳朵连在一起；眼睛是黑斑里的白色小圆点。
4. **鼻子和嘴**：小小的实心黑鼻头；开心时咧嘴、吐出一点舌头（舌头中间一条线）。
5. **身体**：白色，背上一块黑斑；短尾巴向上弯；四条短腿，脚掌用两三道短线表示脚趾。

**转身时：** 竖耳和折耳跟着身体转——背面图里竖耳在观众右边。黑斑的位置不随角度"换边"。

## 4. 使用规则

- 小狗**不拿书**，也不做"正在读书的狗"（避免让用户觉得自己被当成狗），这一条和设计规范一致（`docs/design-system.md` 第 12 节）。
  读书的是 Ricky；小狗陪在旁边、探头、看着他。
- 在设备界面里，小狗按设计规范只在首页（从卡片后探头）和"小狗伴读"模式里出现。
- Logo 本身（圆形徽章 + RickyOS 字样）不改；设定图用于 Logo 以外的场景。
- 新画面先对照第 2、3 节逐条检查锚点，再用于发布。

## 5. 重新出图

设定图用 codex 内置的图片生成画出，参考图是 Logo 和已定稿的四视图。重画或画新场景时：

- 同时附上 `approved-logo.png`、`ricky_turnaround.png`、`puppy_turnaround.png` 作为参考；
- 把第 1–3 节的锚点原样写进提示词，并写明"所有非黑区域必须纯白、不要灰色"和"阅读器是白屏"；
- 出图后对照锚点检查；浅灰底色可以在后期统一转成纯白。
