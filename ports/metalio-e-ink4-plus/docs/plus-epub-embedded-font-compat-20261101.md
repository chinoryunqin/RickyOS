# Plus EPUB 内嵌字体兼容修复（2026-11-01）

状态：代码、构建与主机回归通过，未刷机、未发布。基于当前 Plus 蓝牙体验分支；不包含 Pico 适配。

## 原书复现

用户提供《浪潮之巅（第四版）（上下册）》EPUB。章节 UTF-8 可严格解码，部分正文却将
正常汉字映射成 CJK 扩展字符，再通过 `mxdmm4h1915` 内嵌字体显示原有字形。
包内存在一份 1,928,456 B 的 OpenType/CFF 字体。不能用替换乱码字符表或切换系统字体解决。

实际 CSS 解析器复现：原样加载时 BOM 导致第一个 @font-face 丢失；仅去掉 BOM 后，
只记录不存在的 EOT；候选中的 `url(...) format(...)` 闭括号与带冒号的 ZIP 文件名也未正确处理。
另核实实际 FreeInkFont 构建仅注册 TrueType，未编入 CFF，单独修 CSS 仍无法渲染该字体。

## 实现范围

- CssParser：流开头 UTF-8 BOM；有界 8 个 TTF/OTF URL 候选；正确分离 format；
  允许 ZIP 路径段内冒号，继续拒绝 URI scheme、协议相对 URL 与越过书根目录的路径。
  不增加远程字体下载，不支持 EOT/WOFF/SVG 字体容器。
- BookFontSet：仅保留归档内存在、满足原大小限制的候选元数据；字节仍按需读取。
  损坏字体可回退到同族下一候选；内存不足继续采用原预留/退避，不借回退绕过内存检查。
- 字体引擎：在现有 FreeType 2.13.3 中添加同版本 CFF、PSAux、PSHinter，启用必需的 PSNames；
  不升级整个字体引擎，不修改 TrueType 渲染选项、抗锯齿、字重、刷新波形或内存分配器。
  新模块来源为 FreeType 官方 VER-2-13-3，provenance.json 记录归档与逐文件 SHA256；
  保留 FTL/GPLv2 授权，选择 FTL。包装文件编译期拒绝与不同版本核心混用。

## 内存与缓存影响

FontFaceReader 原有堆工作区增加固定 8 个字符串槽，避免将候选放进任务栈或累计整份 src。
每个 src 片段仍受原 256 B 缓冲限制，CSS 字体总数/字节池与 BookFontSet 总数限制不变。
候选槽只存路径，不同时载入所有字体文件。字体失败会释放其字节，退出释放已加载字体。
保留单文件 4 MiB 上限、单字形缓存 384 KiB 上限、512 KiB PSRAM 预留与 15 秒内存退避。
本书成功加载时会实际占用原有内嵌字体路径的约 1.84 MiB 字节和字体引擎/字形缓存；
这是此前未成功加载过的字体工作集，不能声称整体内存零增加。
网络、USB、蓝牙开关和它们的预留配置未因本次修复修改。

CSS 缓存语义版本 14 → 15，BookFontSet 外观键修订 4 → 5。未更改二进制记录布局。
旧 CSS 和精排分页按正常打开路径惰性重建，保留书籍、书签、阅读进度；不启动全盘清缓存。
原书字体的字宽可能与错误回退字体不同，因此受影响的书会重新分页。
关闭原书样式时仍遵循原有用户设置，不宣称重映射字体在强制忽略内嵌字体模式下可正常显示。

## 首次真机发现的栈溢出与修正

用户授权刷入 bt6，写后摘要及非应用区域检查通过，但恢复阅读该 CFF 书时
ActivityManager 渲染任务栈溢出，不能算启动/阅读验收通过。
目标 GCC 使用实际生产编译参数（仅关闭 LTO 以产生 .su）测得原
`cf2_interpT2CharString` 单函数栈为 16128 B，渲染任务总栈只有 16384 B。
原主机测试使用桌面栈，因此未覆盖这个硬件约束。

修复不扩大内部任务栈，四个 hint-map 改为每次解释调用的一块 FreeType 内存工作区，
继续通过已有 PSRAM 优先分配器；没有进程全局共享 scratch，不改变递归语义或字体波形。
分配失败先返回 FreeType 错误，尚未初始化其他资源；所有正常/错误出口释放工作区。
目标编译器同一函数栈降为 496 B。新增工作区为有界的单调用结构，峰值增加需计入字体内存。
原厂 FreeType 源文件唯一适配为 src/psaux/psintrp.c，provenance.json 同时保留上游和适配摘要。
候选改为 bt7，待编译和再次真机验证；bt6 不得继续分发。


### bt7 构建与 CFF 内存/栈验证

`cf2_interpT2CharString` 目标编译栈 496 B，`cff_slot_load` 1552 B；新增目标编译器栈预算测试，
每个函数上限 2048 B，并加入 port 回归入口。最终 ELF 反汇编确认前者 push 112 + 384 = 496 B，
不是仅凭无 LTO 的主机估计。任务栈仍为原 16384 B，未修改内部预留。
