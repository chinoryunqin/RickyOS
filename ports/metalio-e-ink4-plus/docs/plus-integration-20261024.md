## 交叉改动的处理

### 白底正文与阅读背景分路

图库原提交把灰 8～14 的保擦除处理直接写进共用 `MY_MODE_READER_TURN`，会同时改变
已验收普通正文的 AA 灰边。本次保留两份不同用途的表：

- Profile 1 / `MY_MODE_READER_TURN`：与本地验收前的白底正文表一致；允许正文 AA 完成时刻对齐。
- Profile 5 / `MY_MODE_READER_PAPER_TURN`（port-private `0xC`）：保持图库的浅灰擦除序列；不套正文 AA 时序。
- Profile 2：周期、手动、精排面板清理，仍走 GC16。
- Profile 4：区域 UI，不受背景阅读表影响。

复用图库已有 2368 B 擦除快照作为最终背景阅读表，无额外 heap、framebuffer 或整相位表。
新增仅为静态 waveform descriptor／指针；驱动 one-shot profile 在提交／取消后消费。
背景路径仍支持原生空间动效，不要求打开抗锯齿；普通白底文字的字重与 gamma 不变。
背景使用分支既有阈值（目标灰 8～14），不在本次合并擅自调整灰阶或电压参数。
