# 阅读绑定增补（2026-10-30）

基线：正式发布标签 `plus-v1.2.11`，提交 `9302f06e8a82f66063b7c5c226f6087b61750902`。
独立分支：`codex/plus-reader-bindings-20261030`。不包含其他分支的注解等开发功能。

## 操作

- 阅读触摸区域 → 竖屏或横屏触摸区 → 任意格子 → **查看目录**。直接打开章节列表，取消返回阅读，选择章节后跳转。两套布局独立保存，仍须至少保留一个阅读菜单格。
- 系统 → 按键 → AI、底部上一页／下一页、侧边上／下键 → 短按或长按 → **加入书签**。主页触摸键的单击／双击／长按动作也可选此项。
- 新书签动作只添加：当前页已有书签时保留，不重复创建或删除。原有「书签」切换动作保持原语义。
- 新动作仅在正文阅读时生效；打开目录、菜单或弹窗后由当前界面接管输入。查看目录和加入书签会停止自动翻页。正文链接仍优先于九宫格动作。

## 配置与资源

九宫格 `Contents=5`、Plus 按键 `Bookmark=11`、主页语义动作 `AddBookmark=14` 均追加在原动作末尾，旧编号、默认布局和既有绑定不变。设置 JSON 的结构与版本不变，新值通过既有校验和保存流程处理；更旧固件不能执行新动作。

坐标检测和按键映射没有新增堆分配、帧缓冲或后台任务。目录沿用原 `EpubReaderChapterSelectionActivity`：需要跨帧存活，由活动栈通过 `startActivityForResultWith` 可失败分配，大小为 `sizeof(EpubReaderChapterSelectionActivity)`；打开前按原流程释放当前 section，分配失败请求重画恢复阅读。书签复用原位置匹配、容器与保存流程。

实际修改位于 `firmware/rickyos-plus-1.2/upstream/`，可还原变更记录在 `port-changes.json` 与 `upstream-plus.patch`。与正式版对比，仅修改两个动作涉及的 12 个源文件。
