# Metalio E-Ink4-Plus 新功能接入

2026-10-12。应用基线仍为 24c05ff7，选择性引入设计分支 6e1d0ea7111d70596295c730ea8a3a84814932cb 的拼音、区域灰阶策略和透明待机；没有合入 Read Pico 的电源／USB 硬件配置。

## 已实现

- 拼音：普通文本输入支持中英文切换、组合串、每页 5 个候选及翻页；密码／网址沿用原输入方式。固定会话状态约 1162 字节，不增加每键堆分配，不使用网络；409 音节字典及 pypinyin MIT 许可随源码记录。Plus CMake 显式编译 PinyinInput.cpp。
- 原生灰阶区域刷新：用 4-bit front/back 的真实差异区分内容和导航。普通提交使用 GL16，内容累计 8 次、局部控件和导航 32 次触发区域 GC16；一次最多两个提交。相同帧不开显示电源、不计数；成功后才更新账本。失败将整个光学基准置未知，下一次物理清白／全刷恢复。保留阅读器已有 profile 和手动全刷覆盖。
- 厂商区域提交修正：difference 内核计算整行的脏列，原高层又复制整行 back_fb。新的 update_region 将区域按 32 像素对齐、屏蔽外部脏列，成功后仅发布实际提交范围；区域 GC16 包括该范围内未变化像素，用来清理累计残影。
- 透明待机：新增透明 PNG 选择／移除及图片页“设为透明壁纸”。使用最后成功的 EPDiy back_fb 恢复 native 前缓冲，并从 4-bit 基准重建 B/W proxy；复用现有空间，无额外截图分配。解码失败丢弃全部部分结果，恢复原页；同次待机只叠加一次 alpha。未知基准／反色退回原保留页面。PNG 解码器与行缓冲按需分配，提交前释放。
- 保留本机前光、音量、待机关灯／停音频、盖板键、电量、网络迁移修改。
