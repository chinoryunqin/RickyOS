# 原生翻页动效：2026-10-24 本地实验

## 基线与范围

- Pico 基于正式 1.2.6 `ee569c14`，工作分支 `codex/pico-reader-compact-20261024`。
- Plus 基于正式 1.2.6 `dc151595`，工作分支 `codex/plus-reader-compact-20261024`。
- 包含前一轮尚未提交的紧凑阅读区改动，保留上述基线中的阅读、图片、词典、壁纸、电量和书库功能；未同步其他并行实验分支。
- 仅本地体验，未提交、未推送、未发布；描述版本仍为 1.2.6，不能当作新的正式包。
- Plus 仍严格使用补丁 IDF `9a97f6c54ec638111ce55cd36581b3c192f15207`。

## 操作入口

设置 → 显示 → 翻页动效（实验）：关闭 / 掠页 / 柔弧。默认关闭；读取旧配置、缺键及越界值回到关闭。
选好后打开纯文字书，在同一章节前后翻页；首次打开、跨章、含图页及周期全刷不启用动效。
目前仅 EPUB reader 管线及走该管线的 TXT/MD/未加密 Kindle 导入内容，不覆盖独立漫画/图片/PDF viewer。
不是连续卷页或拖拽动画，也不承诺与浏览器概念预览逐帧一致。

## 实现与约束

1. 下一页按原流程渲染，前后帧差分一次；原生扫描中按 16×16 源像素网格选择各自的局部相位。
2. 掠页采用 smoothstep 的八级起始偏移 0..7；柔弧在逻辑 Y 轴加入浅弧。方向跟随实际前后翻页及左右方向设置；映射覆盖四种屏幕方向。
3. 每个区域完整执行当前设备波形的所有相位，未开始/已结束输出 HOLD，不平移文字，不增加黑白底图重放，不改电压/线时钟/灰阶 LUT。
4. Pico 保留 held-diagonal text-turn 波形及原差分掩码；Plus 保留正文黑到黑重驱和未变化 chrome 保持，避免倒退淡墨修复。
5. 只在实际相邻同章节翻页、上一页为成功的原生纯文字页、方向未变、无 CSS 灰面板、非周期清理时请求动效。请求在下一次提交消费；取消、无差分、电源失败也清除。
6. 底层只接受完整差分光栅、1KiB 紧凑 LUT、有效朝向、2..64 相位和固定相位时间；不符合或 OOM 在任何驱动前回退普通扫描。
7. 原生 bank/网格是每次扫描临时 PSRAM，不新增帧缓冲、不占 C3 常驻大块 RAM。37 相位、1216×684 时为 37×1024 + 76×43 = 41,156 字节；最多 64 相位时 68,804 字节。成功、失败都在 feeder 退出后释放。
8. 失败不提交新 back buffer；原有 Unknown 光学状态和清屏恢复路径保留。低层生产代码不依赖竞争项目的新组件，本次调度/几何为自行实现，沿用 vendored EPDiy 的 LGPL 标注。
9. Plus 第一轮动效暂不走原有 phase-lookahead：它假设一帧共用一张可变 LUT；动效用只读 bank，先沿用安全同步阶段路径。关闭动效时原有 lookahead 不变。
10. 动效比普通波形最多多 7 次全行扫描，Plus 还可能增加非 lookahead 间隙；这是效果实验，不是翻页加速。未测实际耗时/能耗，不能宣称更快或更省电。

- 两台 3 项新测试通过，包括新增中文菜单在 caption/headline/title 真正字形覆盖。
- Pico 实际 EpdiyLcd wrapper + highlevel 事务测试通过（diagnostics 0/1、无差分消费、取消、全刷不动画、失败后 GC16 恢复、PMU 及初始化 OOM）。命令带 `--transactions-only`；旧资源总测试使用 GNU ld --wrap，未当作 macOS 已通过。
- Pico 原有 reader chrome 5、UI 回归 10、页面缓存 4、设计资源 6 项检查通过；生产 GC16/GL16 波形未修改。
- Plus 完整 `run_plus_port_tests.sh` 退出 0，包括 native、reader chrome、字体无损解包、原生缓存和原区域刷新；源审计 2844 文件 / 193 适配通过。
- 两台硬件编译通过；Plus 构建前后 IDF 校验通过。
- Pico 构建曾遇组件 registry 连接失败及不完整 SDK 缓存；已重建完整配置并核对 MDNS_MAX_INTERFACES、PSRAM mDNS 与 USB MSC 启用。之后曾因电脑磁盘空间不足链接失败；仅清理三份无进程占用的 PlatformIO 下载压缩缓存后成功，不删除代码或发布产物。
